# KAZ-TIR CRM / ERP

Закрытый репозиторий исходников локального приложения. Это не публичный запуск
CRM и не копия действующей базы компании. Снимок кода: 16 сентября 2026 года.

## Быстрый безопасный запуск

Требуются Node.js 22 или новее и npm.

```sh
cd app-foundation
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run demo:web
```

Откройте `setupUrl`, выведенный локально в терминале. Ссылка одноразовая:
не пересылайте её. Сервер слушает только localhost. Данные демонстрации
вымышленные, база находится в памяти и исчезает после остановки `Ctrl+C`.
Это интерфейс владельца, а не проверенный вход под учётной записью сотрудника.

Другие демонстрации:

```sh
npm run demo       # Идемпотентный импорт в память
npm run demo:bank  # Предпросмотр вымышленных банковских операций
```

Банковский пример — ограниченный образец проверки, не универсальный загрузчик
XLSX. Он не проводит платежи, не меняет рейсы и не начисляет бонусы.

## Что сохранено

- Исходники интерфейса и локального HTTP-сервера.
- Миграции PostgreSQL/PGlite, проверки ролей и изоляции данных.
- Подготовка, проверка и повторный импорт снимков без создания дублей.
- Карточки сотрудников, точные соответствия имён и ролей.
- Рабочая карточка рейса, черновики, контроль версий и переходов статусов.
- Настройки вознаграждений и предварительные расчёты зарплаты.
- Предпросмотр банковских операций и отдельный слой решений владельца.
- Автоматические тесты и синтетические данные для независимой проверки.

## Что намеренно не опубликовано

Рабочая база и резервные копии, банковские выписки, выгрузки Google Sheets,
реальные клиенты, перевозчики, реквизиты, индивидуальные условия сотрудников,
ключи API, токены, пароли, cookies, сеансы и одноразовые ссылки.
Привязки к рабочим Google-таблицам и имена в примерах заменены синтетическими.
Исторические Google-таблицы и их Apps Script не являются исходниками этого
локального приложения и не развёртываются этим репозиторием.

## Ограничения и эксплуатация

Это развивающееся приложение, а не принятая в промышленную эксплуатацию ERP.
Нет публичного развёртывания, полноценных индивидуальных входов сотрудников,
автоматического обмена с Google Sheets и банковского проведения.
Предварительные расчёты зарплаты не являются утверждённой ведомостью.

Команды `import:local`, `start:local`, а также `src/register-*.mjs` и
`src/release-*.mjs` — исторические операторские утилиты. Они требуют отдельно
подготовленной частной конфигурации, снимков и резервных копий; не запускайте
их на рабочей базе без адаптации, проверки и согласования. Для знакомства
используйте только команды `demo*` и `test` выше.

[проверки публикации](docs/PUBLICATION.md), [безопасность](SECURITY.md).

Лицензия на публичное распространение не предоставлена.
