# Безопасность

Не публикуйте рабочие данные даже в закрытом репозитории. `.gitignore` не
удаляет секреты из уже созданных коммитов. При утечке сначала отзовите ключ
у поставщика, затем отдельно устраните его из всей истории.

Сервер рассчитан на локальную работу владельца. Не меняйте адрес прослушивания
на внешний и не ставьте публичный туннель: полноценное развёртывание требует
отдельной проверки идентификации, TLS, секретов, восстановления и прав ролей.

Демонстрационные ключи в автоматических тестах не используются рабочей системой.
Демонстрационный веб-сервер создаёт новый случайный ключ при каждом запуске.
Сеансы и рабочие данные исключены из состава публикации.

Изменения прав, денег, назначений и бонусов требуют регрессионных тестов,
резервной копии и проверки чтением после сохранения. Успешные unit-тесты сами
по себе не подтверждают готовность для реальных сотрудников.
